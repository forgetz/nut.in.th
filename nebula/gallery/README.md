# Gallery images

Drop ComfyUI (or any) images here: .png, .jpg, .jpeg, .webp, .avif

- Each build resizes them to WebP and strips metadata (ComfyUI prompts/workflows are NOT published)
- Newest file (by modified time) shows first
- Optional caption: create a text file with the same name, e.g. `ComfyUI_00042_.txt` next to `ComfyUI_00042_.png`.
  First line = title, the rest = description. Use `.th.txt` for a Thai caption (`ComfyUI_00042_.th.txt`)
- Then run `npm run build` (or `npm run deploy` to build and upload)
