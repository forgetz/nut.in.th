## คืออะไร

nut.in.th เวอร์ชันที่สาม เปลี่ยนจากเว็บ PHP เดิมมาเป็นการ build แบบ static เพื่อให้วางบนโฮสติ้งที่รับไฟล์ธรรมดาได้ทุกที่

## รายละเอียด

- ทุกหน้ามีทั้งภาษาไทยและอังกฤษ รวมถึงข้อกำหนดการใช้งานและนโยบายความเป็นส่วนตัว
- แกลเลอรีที่ดึงภาพทุกไฟล์จากโฟลเดอร์เดียว แล้วย่อขนาดให้ตอน build
- คำสั่งเดียว build และอัปโหลดขึ้นโฮสติ้งผ่าน FTP
